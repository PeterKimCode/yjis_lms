# Upload Security

The local MVP accepts assignment submission attachments through the LMS app only.
Files are stored in MinIO, while PostgreSQL stores FileAsset metadata.

## Current Controls

- Maximum assignment attachment size: 20 MB.
- Allowed extensions: PDF, Office files, text, Markdown, CSV, common images, and ZIP.
- Blocked executable/script extensions include `.exe`, `.bat`, `.cmd`, `.ps1`, `.js`, `.sh`, `.html`, `.svg`, `.sql`, and related runtime/script formats.
- SVG and HTML are blocked because they can execute script in browser contexts.
- SQL is blocked because database scripts should not be accepted as normal assignment files.
- Filenames are sanitized before display and storage key generation.
- Storage keys are generated by the app and include organization, class, assignment, user, and a random UUID.
- Downloads go through `/api/files/[fileId]/download` with permission checks.
- Raw MinIO URLs are not shown in the LMS UI.

ZIP files are allowed for the local MVP, but production should treat archives as
higher-risk uploads.
