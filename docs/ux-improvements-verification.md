# 전체 역할 UX 개선 검증

검증일: 2026-10-04. 운영 데이터와 분리한 데모 DB·Redis·MinIO와 로컬 앱을 사용했다.

## 자동 검사

- `npx tsc --noEmit`, `npm run lint`, `npm run build`: 통과.
- `npm run test:security`: 관리자 조직·캠퍼스 권한 검사 통과. 서버 액션 감사의 기존 55개 raw throw 후보는 정보성 보고다.
- `npx tsx scripts/ux-flow-check.ts`: 학교 자정, 7일 범위와 DST, 완료·재응시·종료·비공개 판정 3개 검사 통과.
- 기존 assessment-system, quiz-editor, instructor-class-navigation 검사: 총 16개 통과.
- PDF 7개, 총 88쪽의 텍스트·목차·책갈피·쪽 번호·페이지 밖 텍스트 검사와 렌더링 시각 검수 통과.

## 브라우저 확인

- Super Admin, School Admin, Academic Staff, Instructor, Student, Parent: 접기와 새로고침 유지, 계정별 기본 상태 분리 확인. 관리자 키보드 Enter 펼치기 확인.
- 강의 생성·수정의 닫기 → Stay/Leave, 복원·버리기, YouTube 유형과 주소 복원, 정상 저장 후 임시 저장 제거 확인.
- 과제 제목·설명 복원과 정상 저장 확인. 시험 객관식 문제·보기·정답·7점 합계 복원과 초안 저장 후 Exams / Quiz 복귀 확인.
- 시험 편집 중 브라우저 뒤로가기 → Stay → 다시 뒤로가기 → Leave를 확인했다. 같은 URL의 보호용 히스토리 항목으로 Next가 폼을 먼저 해제하지 않도록 했다.
- 로그아웃 후 같은 교수 계정에 다시 로그인했을 때 수정 초안이 남지 않는 것을 확인했다.
- 학생 할 일에서 오늘·7일 이내·마감 초과·기한 없는 과제를 확인하고 직접 과제 제출 팝업과 PDF 시험을 열었다.
- PDF 서술형 제출 후 채점 대기, 허용된 두 번째 응시, 최대 횟수 후 재응시 버튼과 할 일 항목 제거 확인. 결과 미공개 상태에서 점수를 표시하지 않는 것 확인.
- 학부모 Overview와 자녀 요약에서 공개 시험만 표시하고, 시작·종료 시간과 Asia/Seoul 기준이 수업 화면과 동일한 것을 확인했다.
- 320px·375px·768px와 데스크톱에서 학생 평가·답안과 관리자 사용자 목록을 확인했다. 320px 문서 폭은 305px로 뷰포트 안에 들어가며 답안란 높이는 128px, 제출 버튼이 하단 메뉴와 겹치지 않는다.
- 모바일 표/카드 전환 시 동일한 폼을 두 번 마운트하지 않도록 수정하고 과제 제출 팝업이 한 개만 열리는 것을 확인했다.
- 과제 팝업을 닫은 뒤 모바일에서 데스크톱 폭으로 바꾸어도 다시 열리지 않도록 했다. 닫기 → 1024px 전환 후 팝업 0개를 확인했다.

브라우저 확장에 로컬 파일 접근 권한이 없어 이번 UI 자동 검사에서 새 로컬 PDF 선택은 완료하지 못했다. 권한을 확대하지 않았다. 파일 자체는 임시 저장하지 않는 구현과 재선택 안내, 업로드한 참조의 현재 옵션 검증은 코드로 확인했다. 파일 업로드 기능과 서버 저장 권한은 기존 구현을 유지한다.

## 게시

소스·문서·새 데모 캡처만 main에 게시한다. 운영 배포는 `deploy-lms`의 GitHub 동기화·빌드·기존 마이그레이션·앱 재시작·헬스 검사 절차를 사용한다. 이번 변경에 새 DB 마이그레이션은 없다.
