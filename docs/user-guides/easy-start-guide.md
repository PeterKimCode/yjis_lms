# 처음 쓰는 분을 위한 GTCC YJIS LMS 안내

이 문서는 컴퓨터 사용이 익숙하지 않은 보호자, 선생님, 관리자도 따라 할 수 있도록 만든 쉬운 안내서입니다.

## 전체 흐름

1. 관리자가 계정을 만듭니다.
2. 관리자가 과목과 수업을 만듭니다.
3. 선생님이 영상 레슨, 출석, 과제, 퀴즈를 관리합니다.
4. 학생이 영상을 보고 과제를 제출합니다.
5. 학부모가 자녀의 출석, 과제, 성적을 확인합니다.

## 관리자: 사용자 만들기

1. `Users` 메뉴를 누릅니다.
2. `Create user` 영역을 찾습니다.
3. 이름, 이메일, 임시 비밀번호, 역할을 입력합니다.
4. 학생은 학년, 반, 학생 번호도 입력합니다.
5. `Save`를 누릅니다.

같은 이메일은 다시 만들 수 없습니다.

## 관리자: 수업 만들기

1. `Courses`에서 과목을 먼저 만듭니다.
2. `Class Sections`로 이동합니다.
3. `Course`를 선택합니다.
4. 수업 이름과 정원을 입력합니다.
5. 선생님과 학생을 연결합니다.
6. `Save`를 누릅니다.

## 선생님: 영상 레슨 만들기

1. `Classes`에서 수업을 엽니다.
2. `Lessons` 섹션에서 `Create lesson`을 엽니다.
3. 제목을 입력합니다.
4. Type은 `VIDEO`를 선택합니다.
5. YouTube 또는 HTML5 영상을 설정합니다.
6. 학생에게 보이게 하려면 `Published`를 체크합니다.
7. `Save`를 누릅니다.

## 선생님: 출석 체크

1. 수업 안에서 `Attendance`를 찾습니다.
2. `Manage attendance`를 엽니다.
3. 기본값은 `PRESENT`입니다.
4. 결석이나 지각 학생만 바꿉니다.
5. 전체 저장 버튼으로 한 번에 저장합니다.

## 선생님: 과제와 퀴즈

과제는 `Assignments`에서 만들고, 퀴즈는 `Quizzes`에서 만듭니다.
학생 제출물은 `Review submissions`에서 확인하고 점수를 저장합니다.

## 학생과 학부모

학생은 자기 수업, 레슨, 과제, 퀴즈, 성적만 볼 수 있습니다.
학부모는 연결된 자녀의 정보만 볼 수 있습니다.
