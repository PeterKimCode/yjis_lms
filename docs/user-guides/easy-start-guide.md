# 처음 쓰는 분을 위한 LMS 공통 시작 안내

**사용 주소: [https://lms.mygtcc.com](https://lms.mygtcc.com)**

이 안내는 컴퓨터·휴대전화 사용이 익숙하지 않은 분을 위한 공통 시작 방법입니다. 학교에서 받은 Login ID와 비밀번호를 준비하세요. 화면 예시가 있는 [큰 글씨 PDF](../manuals/easy-start-guide.pdf)를 함께 보면 쉽습니다.

## 1. 로그인

1. 인터넷 주소창에 `https://lms.mygtcc.com`을 입력합니다.
2. `Log In`을 누릅니다.
3. `Login ID`에 학교에서 받은 아이디, `Password`에 비밀번호를 입력합니다.
4. 다시 `Log In`을 누릅니다. 본인 역할의 메뉴가 나오면 완료입니다.

아이디를 모르거나 비밀번호를 잊으면 학교 관리자에게 문의하세요. 대문자·한/영 입력도 확인하세요. 이 시스템에는 누구나 가입하는 회원가입 버튼이 없습니다. `localhost:3000`은 개발자 PC용 주소입니다.

## 2. 내 메뉴 찾기

| 내 역할 | 시작할 메뉴 |
| --- | --- |
| Super Admin | `Users`, `Courses`, `Class Sections`, `Academic setup` |
| School Admin | `Users`, `Courses`, `Class Sections` |
| Academic Staff | 허용된 학교·캠퍼스의 `Users`, `Courses`, `Class Sections`, 학사 메뉴 |
| Instructor | `Classes` → 담당 수업 |
| Student | `Classes` → 듣는 수업 |
| Parent | `Linked students` → 자녀 이름의 `Open` |

권한에 따라 메뉴가 다릅니다. 학교 관리자는 Super Admin을 수정할 수 없으며 가족 연결은 권한 있는 관리자에게 요청합니다. 본인 역할의 [PDF 매뉴얼 목록](../../README.md#쉬운-한국어-pdf-매뉴얼)을 선택하세요.

## 3. 휴대전화 메뉴

1. 위쪽 `Menu`를 눌러 메뉴를 엽니다.
2. 원하는 메뉴를 누르고 `Close`로 닫습니다.
3. 화면 아래 `Home / Classes / Messages / Alerts`로도 이동할 수 있습니다.
4. 수업 안의 긴 탭 줄은 좌우로 밀어 보세요.

수업은 `Lessons / Attendance / Assessments / Grades / Boards / Class conversation` 탭으로 나뉩니다. 교수에게는 `Students`도 보입니다.

## 4. 메시지

컴퓨터 왼쪽 메뉴의 `Collapse sidebar`를 누르면 접고, `Expand sidebar`를 누르면 펼칩니다. 이 계정의 접기 상태는 현재 브라우저에 기억됩니다. 휴대전화 메뉴는 따로 열고 닫습니다.

1. `Messages`를 누르고 기존 대화를 선택합니다.
2. 아래 `Message`에 글을 쓰고 `Send`를 누릅니다.
3. 대화에 새 글이 나타나면 전송 완료입니다.
4. 내 글은 `Edit`로 메시지 안에서 고치고 `Save`로 저장합니다. `Delete`는 글을 지웁니다.

새 대화는 `Recipient`에서 받는 사람을 고른 뒤 `Start conversation`을 누릅니다. 현재 메시지에는 파일을 붙일 수 없습니다.

## 5. 알림

`Notifications` 또는 아래 `Alerts`를 누릅니다. 알림 내용을 누르면 관련 화면으로 이동합니다. `Filter`로 골라 보거나 `Mark all as read`로 모두 읽음 처리합니다. 알림이 비어 있으면 새 알림이 없는 상태입니다.

## 6. 저장과 제출

교수는 작성 중 화면을 나가려 하면 `Stay / Leave` 안내가 나옵니다. `Stay`는 계속 작성, `Leave`는 화면을 나가는 버튼입니다. 다시 열 때 `Restore`로 임시 내용을 복원하거나 `Discard`로 버립니다. 임시 내용은 현재 기기에만 7일 보관하며 로그아웃하면 삭제합니다. 선택한 파일은 다시 선택하세요.

학생은 Overview의 `Your tasks`에서 `Today`(오늘), `Due soon`(7일 이내), `Not submitted`(마감 지난 미제출)를 확인하세요. `Open`을 누르면 해당 과제나 시험으로 이동합니다. 날짜와 시간은 학교 시간대 기준입니다.

- `Save`, `Save assignment`, `Save grade`: 작성·수정한 내용을 저장합니다.
- `Save draft`: 시험·퀴즈를 초안으로 저장합니다. 학생에게 공개되지 않습니다.
- `Publish`: 준비한 시험을 학생에게 공개합니다. 문제·정답·일정을 먼저 확인하세요.
- `Submit`, `Submit answers`: 학생이 과제 또는 시험 답안을 제출합니다. 제출 상태가 바뀌었는지 확인하세요.

시험은 `Assessments → Exams / Quiz`에서 봅니다. PDF 시험지를 읽은 뒤 **LMS 답안란에 직접 답을 씁니다.** 시험 시간은 학교 시간대 기준입니다. 미공개 성적·초안은 보이지 않을 수 있습니다.

## 7. 자주 막히는 상황

| 상황 | 먼저 확인할 것 |
| --- | --- |
| 수업이 안 보임 | 로그인 계정·역할, 수업 등록·배정을 학교에 확인 |
| 자녀가 안 보임 | 학교에 학부모 계정과 학생 연결 요청 |
| 영상 진도가 완료되지 않음 | 실제로 100% 시청했는지, 건너뛴 구간과 인터넷 연결 확인 |
| 파일 업로드 실패 | 영상 500MB, PDF·일반 첨부 20MB, 프로필 사진 10MB 제한과 파일 형식 확인 |
| 시험 날짜가 낯섦 | 수업 안의 `Exams / Quiz`에서 학교 시간대·시작·종료 시간을 확인 |
| 성적이 비어 있음 | 교수의 채점·성적 공개 여부 확인 |
| 화면 오류 반복 | 오류 번호와 수업·메뉴 이름을 적어 학교에 문의 |

## 8. 사용 마치기

작성한 내용을 먼저 저장합니다. 왼쪽 아래 또는 휴대전화 메뉴 아래 `Logout`을 누릅니다. 로그인 화면으로 돌아왔는지 확인한 뒤 인터넷 창을 닫습니다. 공용 컴퓨터에는 비밀번호를 저장하지 마세요.
