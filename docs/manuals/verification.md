## 화면과 권한 대조

독립 DB·Redis·MinIO의 데모 환경에서 6개 역할로 로그인해 화면을 확인했다. 운영 사용자 자료나 비밀번호를 문서에 넣지 않았다. 이번 변경은 앱 표시와 사용 흐름을 개선하며 DB 구조와 권한은 유지한다.

- 관리자의 조직·캠퍼스 범위를 `scope-rules.ts` 및 사용자 상세 화면과 대조했다. School Admin의 Super Admin 수정·삭제 금지, 생성 가능한 Instructor·Student·Parent 역할을 안내했다.
- School Admin 사용자 상세에서는 가족 연결·상세 학사 서류 영역을 제공하지 않는다. Academic Staff는 해당 기능이 표시되는 실제 데모 계정과 허용 범위를 확인했다. 역할 이름만으로 가능한 작업을 추정하지 않았다.
- 최신 수업 탭, Assessments 내부 Assignments 및 Exams / Quiz, 시험 유형, 학생 미리보기, PDF 답안란, 과제 첨부 관리, 인라인 메시지 수정과 강의 그룹 이동을 현재 화면 및 구현과 대조했다.
- 영상은 파일 선택 시 업로드하며 수동 길이 입력 없이 실제 시청 기록 100%로 완료 처리한다. PDF·일반 첨부·학생 제출 20MB, 영상 500MB, 프로필 10MB 제한을 확인했다.
- 시험 일정은 수업 상세에서 조직 시간대로 표시한다. 기본값은 Asia/Seoul이다.

### 기존 화면의 확인 범위

학부모 Overview/자녀 요약의 초안 노출과 UTC 날짜 표시를 수정했다. 공개 시험만 표시하고 학교 시간대·시작·종료 시간과 기존 결과 공개 정책을 적용한다. 새 Overview 캡처와 안내 페이지를 추가했다. 학생 할 일, 교수의 복원·버리기 화면도 새 캡처로 추가했다. 기능이 그대로인 작업은 이전 데모 화면을 유지했다. 학부모 성적 설명의 이미지는 같은 성적 구조의 학생 데모 화면임을 명시했다. 모바일 메뉴는 학생 화면을 공통 예시로 쓰고 역할별 메뉴 차이를 설명했다.

## 제작·검증

- `npx tsx scripts/generate-manual-pdfs.ts`: 7개 PDF 생성 성공. `--only instructor-manual.pdf` 단일 재생성도 확인했다.
- `python docs/manuals/source/verify_manuals.py`: 모든 88쪽을 Poppler로 PNG 렌더링했다. 원문 텍스트·쪽 수·목차 링크·책갈피·쪽 번호·페이지 밖 텍스트 검사 통과.
- 모든 페이지 확인 이미지를 시각 검수하고 대표 페이지를 확대해 한글·번호·버튼·줄 간격을 확인했다. 작은 입력칸 확대와 번호 겹침을 수정했다.
- README 및 문서 상대 링크를 확인했다. PDF 생성기는 로컬 JSON·이미지·글꼴만 읽는다.
- `npx eslint scripts/generate-manual-pdfs.ts`, `npx tsc --noEmit`: 통과.
- 이번에는 앱 UX 변경과 함께 게시하며 기존 `deploy-lms` 절차로 배포한다. 문서만 수정하는 후속 작업은 앱 재배포가 필요 없다.
